# Baltijas Biljards Nr.1 — сайт + скрытая админка

Тёмно-зелёная тема («сукно») по умолчанию. Светлая: `THEME=light node build.js`.

## Запуск локально
    npm run dev        # build + сервер на http://localhost:3000
Админка: тройной клик по логотипу вверху слева. Логин/пароль — у владельца сайта.

## Публикация (нужен сервер с API, иначе админка не сохранит)
* **Netlify через CLI или Git** (не «перетаскиванием папки» — функции и хранилище так не деплоятся):
  `npm i -g netlify-cli && netlify deploy --prod`. Хранилище — Netlify Blobs.
* Любой Node-хостинг: `npm run build && npm start` (данные в `./data`, задайте `DATA_DIR`).
* Без API сайт показывает стандартное содержимое, админка недоступна.

## Смена пароля (обязательно!)
Переменные окружения: `ADMIN_LOGIN`, `ADMIN_PASSWORD`, `ADMIN_SECRET` (случайная длинная строка).

## Фото
Положите файлы в `assets/img/` (имена — в build.js, SLOTS) или меняйте в админке: вкладка «Фото».
Лимит загрузки 4.5 МБ (фото сжимаются автоматически).

## Админка
Фото · Новости (посты) · Турниры (положение + ссылка на TournamentService) · Правила · Магазин (товары, цены, описания LV/RU/EN) · Галерея (клуб/турниры) · Прайс-лист · Настройки (часы работы).
